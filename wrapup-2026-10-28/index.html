    Shardik rebuild (192.168.1.2)

    Item Result
    Motherboard ASRock B450M Steel Legend (from futurepve), BIOS P2.10 — kept (P2.50 is the last BIOS without ASRock's Summit Ridge warning; flash skipped)
    CPU Ryzen 5 1600X (Zen 1)
    RAM 64GB — 4× PNY XLR8 16GB DDR4-3200 (16GF2X16GFH36-135-K-HXR), set manually to DDR4-2133, XMP off
    GPU Quadro 600 (console only)
    Boot Intel 760p 256GB NVMe (SSDPEKKF256G8L), ext4/LVM, single drive (Toshiba XG6 not detected — dropped)

    Front panel Power switch was on wrong header pins — fixed (photo taken)
    SATA 4 ports / 5 CRU bays — one bay unwired by design; port 2 cable was disconnected — fixed

    Root cause of freezes

    • Hard lock ~15 min after boot, no log output → Zen 1 idle C-state freeze
    • Fix: BIOS → Advanced → AMD CBS → Zen Common Options → Global C-state Control = Disabled (Power Supply Idle Control not present on P2.10)

    Other BIOS settings

    • SVM Mode Enabled, IOMMU Enabled, Restore on AC Power Loss Power On, Fast Boot Disabled, Secure Boot off, clock corrected (CMOS had reset to 2019)

    SATA cable test (50GB write + read + scrub) ✅ CRC counts unchanged

    Uptime 22h+ with no lockups since C-state fix
