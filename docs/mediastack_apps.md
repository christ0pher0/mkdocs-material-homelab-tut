# MediaStack Applications

| Status | App | Description |
|--------|-----|-------------|
| ⬜ | **[Authelia](https://www.authelia.com/)** | Authentication and access control layer for securing exposed applications. |
| ⬜ | **[Bazarr](https://www.bazarr.media/)** | Automates downloading of subtitles for movies and TV shows. |
| ⬜ | **[DDNS-Updater](https://github.com/qdm12/ddns-updater)** | Automatically updates dynamic DNS records when your home IP address changes. |
| ⬜ | **[Readarr](https://wiki.servarr.com/)** | Library manager automating the management and metadata for eBooks. |
| ⬜ | **[Tdarr](https://tdarr.io/)** | Automates transcoding and management of media files — requires GPU node. |
| ✅ | **[Audiobookshelf](https://www.audiobookshelf.org/)** | Audiobook and podcast server with progress tracking and mobile apps. |
| ✅ | **[FlareSolverr](https://github.com/FlareSolverr/FlareSolverr)** | Bypasses Cloudflare protection, allowing Prowlarr to access protected indexers. |
| ✅ | **[Gluetun](https://github.com/qdm12/gluetun)** | Routes network traffic through a VPN (Surfshark WireGuard), ensuring privacy for Docker containers. |
| ✅ | **[Homepage](https://gethomepage.dev/)** | Dashboard for accessing and organising web applications and services. |
| ✅ | **[Kometa](https://kometa.wiki/)** | Automates Plex metadata, collections, and artwork using Trakt and MDBList. |
| ✅ | **[Komga](https://komga.org/)** | Comics and manga library server with reader support. |
| ✅ | **[Lidarr](https://lidarr.audio/)** | Library manager automating the management and metadata for music media files. |
| ✅ | **[MariaDB](https://mariadb.org/)** | Database backend for RomM. |
| ✅ | **[Mylar3](https://mylarcomics.com/)** | Library manager automating the management and metadata for comic media files. |
| ✅ | **[Plex](https://www.plex.tv/)** | Media server that organises, streams, and manages multimedia content across devices. |
| ✅ | **[Prowlarr](https://wiki.servarr.com/)** | Manages and integrates indexers for media download applications, automating search and download. |
| ✅ | **[qBittorrent](https://www.qbittorrent.org/)** | Peer-to-peer file sharing application for downloading and uploading torrents. |
| ✅ | **[Radarr](https://radarr.video/)** | Library manager automating the management and metadata for movie media files. |
| ✅ | **[RomM](https://github.com/rommapp/romm)** | ROM manager with metadata, artwork scraping, and web-based library browser. |
| ✅ | **[SABnzbd](https://sabnzbd.org/)** | Usenet newsreader that automates the downloading of binary files from Usenet. |
| ✅ | **[Seerr](https://github.com/seerr-team/seerr)** | Request management portal for Movies and TV, integrated with Plex. |
| ✅ | **[Sonarr](https://sonarr.tv/)** | Library manager automating the management and metadata for TV show media files. |
| ✅ | **[Unpackerr](https://github.com/Unpackerr/unpackerr)** | Extracts downloaded media files and moves them to appropriate directories. |
